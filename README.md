# Condensation and Inclusion

This is the source of the Condensation and Inclusion website.
Serve this directory with `python3 -m http.server 8000` for a local preview.
The site uses GitHub Pages with the root of the `main` branch as its source.

The Sticky Inclusion topic contains the public proof, source records, and
animation from the earlier site. The Raw page retains its proof text and
review status. See the source record linked there for the earlier versions.
The two other topics contain reading notes and research questions.
